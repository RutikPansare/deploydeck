
# DeployDeck

A self-service cloud deployment platform built using AWS and DevOps technologies.

## Vision

Deploy applications to AWS through a simple dashboard with automated CI/CD, containerization, monitoring and rollback capabilities.

## Planned Technologies

- AWS
- Docker
- Python (FastAPI)
- React
- GitHub Actions
- Terraform
- AWS ECS
- AWS ECR
- CloudWatch

## Project Status

Development in progress.
